# Atividade Java - Sistema de Estoque de Produtos

Projeto corrigido conforme o enunciado.

## Executar
- VS Code: abra a pasta e execute `EstoqueApp.java`.
- IntelliJ IDEA: abra a pasta como projeto Java e execute `EstoqueApp`.
- Terminal: `javac *.java` e depois `java EstoqueApp`.

O programa demonstra as classes exigidas, herança, classe abstrata, interface, polimorfismo, sobrecarga, composição e as duas exceções solicitadas.
